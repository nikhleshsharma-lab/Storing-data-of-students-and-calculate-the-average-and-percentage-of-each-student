# Python Loop Patterns

A beginner-friendly Python project created as part of my first-semester Computer Science and Engineering (CSE) learning journey.

This repository contains Python programs focused on loops, nested loops, and pattern printing. The goal is to strengthen programming fundamentals and logical thinking through practical exercises.

## Concepts Covered

- `for` loops
- Nested loops
- Star patterns
- Number patterns
- Increasing and decreasing patterns
- Pyramid and diamond patterns
- Basic problem-solving and logical thinking

## Programs Included

| File Name | Description |
|---|---|
| `right_triangle.py` | Prints a right triangle using stars |
| `inverted_right_triangle.py` | Prints an inverted right triangle |
| `half_diamond.py` | Prints a half-diamond pattern |
| `diamond_pattern.py` | Prints a diamond pattern |
| `pyramid_pattern.py` | Prints a pyramid using stars |
| `invert_pyramid_pattern.py` | Prints an inverted pyramid |
| `increasing_number_pattern.py` | Prints an increasing number pattern |
| `repeated_number_triangle.py` | Repeats the row number in each row |
| `square_pattern.py` | Prints a square using stars |

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in a code editor.
4. Run a Python file using the terminal:

```bash
python diamond_pattern.py
```

Replace `diamond_pattern.py` with the name of any program you want to run.
